# FurPals 🐾
### A Social Pet Management Platform for Furparents

FurPals is a Flutter-based mobile application that brings pet owners together through a social feed, lost-and-found board, and comprehensive pet management tools. The app allows users to create pet profiles, schedule veterinary appointments, share posts with the furparent community, and discover or post about missing pets. Built on Firebase, FurPals provides real-time updates, secure authentication, and cloud media storage to deliver a seamless and connected experience across Android and iOS devices.

##  Quick Start Guide

### Prerequisites

- Flutter SDK `>=3.11.0`
- Dart SDK `>=3.11.0`
- Android Studio or Xcode (for device emulation)
- A Firebase project (see Environment Setup below)
- Node.js (optional, for Firebase CLI)

### 1. Clone the Repository

```bash
git clone https://github.com/your-org/furpals.git
cd furpals
```

### 2. Install Flutter Dependencies

```bash
flutter pub get
```

### 3. Configure Firebase

Ensure the following files are present (generated by FlutterFire CLI):

- `lib/firebase_options.dart`
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist` *(if targeting iOS)*

If they are missing, run:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

### 4. Run the Application

```bash
# For Android
flutter run

# For iOS
flutter run --target=lib/main.dart

# For a specific device
flutter devices                  # list available devices
flutter run -d <device-id>
```

### 5. Build for Release

```bash
# Android APK
flutter build apk --release

# Android App Bundle
flutter build appbundle --release

# iOS
flutter build ios --release
```

##  Environment Setup

All Firebase configuration is stored in `lib/firebase_options.dart`. The following keys and values must be present and valid for the app to function. These are generated automatically by the FlutterFire CLI when you connect your Firebase project.

| Key | Platform | Description |
|---|---|---|
| `apiKey` | Android, iOS, Web, Windows | Firebase project API key |
| `appId` | All platforms | Firebase App ID (unique per platform) |
| `messagingSenderId` | All platforms | Firebase Cloud Messaging sender ID |
| `projectId` | All platforms | Firebase project ID (`furpals-13a2f`) |
| `storageBucket` | All platforms | Firebase Storage bucket URL |
| `authDomain` | Web, Windows | Firebase Authentication domain |
| `measurementId` | Web, Windows | Google Analytics measurement ID |
| `iosClientId` | iOS, macOS | OAuth client ID for iOS |
| `iosBundleId` | iOS, macOS | iOS app bundle identifier |

### Firebase Services Required

The following Firebase services must be **enabled** in your Firebase console:

- **Authentication** — Email/Password provider enabled
- **Cloud Firestore** — Database in production or test mode
- **Firebase Storage** — For photo and video uploads
- **Firebase Analytics** — Optional, for measurement IDs

### Android-Specific

The file `android/app/google-services.json` must match your Firebase project. The current `package_name` is:

com.example.furpals

### Required Firestore Security Rules (Minimum)
rules_version = '2';
service cloud.firestore {
match /databases/{database}/documents {
match /users/{userId} {
allow read: if request.auth != null;
allow write: if request.auth != null && request.auth.uid == userId;
}
match /posts/{postId} {
allow read: if request.auth != null;
allow write: if request.auth != null;
}
match /notifications/{notifId} {
allow read, write: if request.auth != null;
}
}
}
